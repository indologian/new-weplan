# Animation System

- Simple hover/focus/state: CSS/Tailwind.
- Invitation opening, section reveal, stagger, layout transition: Motion for React.
- Theme-specific presets live in each theme `animations.ts`.
- Open Invitation user gesture starts music.
- Scroll reveals should normally run once.
- Prefer transform/opacity.
- Avoid excessive blur/filter/parallax/continuous JS animation.
- Honor `prefers-reduced-motion` / Motion reduced-motion APIs.
